## 📂 Projects

### 1️⃣ IR Car Timing Game
A real arcade-style timing game where a toy car passes through an IR gate and the timing decides the score.

▶️ **Video Demo:**  
https://youtu.be/aWv_YZRQP7Y

**What happens**
- Car passes through IR sensor
- Game runs for 30 seconds
- Timing decides the score in real time

**Scoring Logic**
- Green zone → Perfect hit
- Red zone → Penalty
- No repeated scoring by holding the car

**Files included**
- Arduino code
- Web-based game UI
- Connection diagram

📁 Folder: `IR-Car-Game-1`
